How to use the editor

  1. 01

    Select a workbench

    Choose a subject and a group. The included Japanese source and current English translation load automatically.

  2. 02

    Edit translations

    Edit the draft and review the text validation messages and game-font preview. Edits are saved in this browser.

  3. 03

    Download changes

    Download a TSV containing your validated changes. Import it into the editor to continue editing, or into the project for review and game testing.

The current game font supports the project’s English glyph set. Other writing systems need additional font support.
