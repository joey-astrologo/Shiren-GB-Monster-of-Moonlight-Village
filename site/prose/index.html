EDITING GUIDE

Prose editing rules

Ordinary prose wraps automatically into boxes of three lines. Each line has room for 30 source glyphs and 144 painted pixels, measured with the game’s actual font.

  • Use <brk> for a deliberate page break, and <br> for a deliberate line break.
  • Keep required control tokens and their order. The wrapper supplies indents and end/wait controls.
  • Structured choice prompts are available as reference in this first version.
  • Shaded preview spans reserve space for runtime names or values. Unknown values still need project checks.

Download a changes TSV and import it into the project for glossary, build and emulator checks. The browser checks text fit; it does not run the game.

Event groups follow the draft’s existing sections and record order. They are not a verified chronological walkthrough.
