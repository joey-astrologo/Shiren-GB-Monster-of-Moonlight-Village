Editing rules and downloads

Each entry shows the rules for its rendering path. Most workbenches retain explicit line breaks and structural spaces. Item descriptions allow line breaks to move within the existing pages; cinematic text wraps into its fixed screen slots. Ordinary dialogue wraps in the prose editor.

Changes from these workbenches share one browser draft and one download. Shared fragments and names are checked against their known consumers. The prose editor keeps its existing separate draft and TSV format.

A download contains only edited entries, their stable keys and baseline checks. The project importer routes them to the correct TSV. Terminology, ROM placement, shared runtime allocation and visual acceptance also need the project build and game checks. A browser fit check does not run the game.

The current font supports the project's English glyph set. Translating into a language that needs other characters requires a font change.
